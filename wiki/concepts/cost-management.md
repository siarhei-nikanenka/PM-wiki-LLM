# Project Cost Management

Из [[pm-16-cost-management]].

Бюджет — не ограничение проекта, а инструмент управления эффективностью: связывает задачи, ресурсы и деньги в единую систему, позволяющую оценивать, какую ценность команда реально создаёт за эти деньги.

## Четыре процесса
- **Plan Cost Management** (планирование) — «правила игры»: единицы измерения (часы, ставки, валюта), ответственность за утверждение бюджета и изменение baseline, периодичность отчётности, инструменты (например, EVM). Результат — Cost Management Plan.
- **Estimate Costs** (планирование) — итеративный прогноз, не разовая цифра.
- **Determine Budget** (планирование) — консолидация оценок в Cost Baseline.
- **Control Costs** (мониторинг и контроль) — отслеживание фактических затрат против Cost Baseline.

PMBOK не покрывает привлечение финансирования — PM работает с уже выделенным бюджетом; поиск и утверждение денег — уровень бизнес-стратегии/портфеля (CFO, инвесторы, клиент, в зависимости от типа компании — см. [[it-company-types]]).

## Оценка стоимости: точность растёт по мере детализации
- **ROM** (order of magnitude) — ±50–100%, на этапе идеи/пресейла.
- **Предварительная оценка** — от +30% до −20%.
- **Точная (definitive) оценка** — ±10–15%.

В IT часто используют альтернативные единицы — человеко-часы/дни/месяцы — удобные для пересчёта при смене рейт-карты.

### Четыре метода оценки
1. **По аналогии** — быстро, субъективно, для пресейла.
2. **Параметрическая** — формула на основе измеримого параметра (например, «$ за экран»).
3. **Трёхточечная (PERT)** — (оптимистичная + 4×наиболее вероятная + пессимистичная) / 6 — та же формула, что и для длительности задач в [[schedule-management]]; учитывает риски и неопределённость.
4. **Bottom-up** — по WBS, самая точная, ложится в итоговый Cost Baseline.

## Determine Budget: структура Cost Baseline
Прямые (операционные) затраты + управленческие расходы + накладные расходы + резерв на риски = **Budget at Completion (BAC)**.

**Операционные расходы:** материалы и оборудование (лицензии, серверы), внешние услуги/вендоры, прямые трудовые затраты (**60–80% бюджета IT-проекта**).

**Аутсорс vs продукт:**
| | Аутсорсинг | Продукт / in-house |
|---|---|---|
| Источник финансирования | клиент по контракту | внутренний бюджет / инвестор |
| Учёт расходов | себестоимость часа (cost rate) + маржа = client bill rate | P&L, инвестиции в продукт |
| Метрики | доходность, утилизация | ROI, retention, ARPU |

## Резерв на непредвиденные расходы (contingency reserve)
Должен быть обоснован через оценку рисков (вероятность × потенциальные потери), а не назначен произвольным процентом. Типичные диапазоны: **1–10%** для повторяющихся проектов, **20–60%** для новых/инновационных, **до 70%** для R&D. Частые ошибки: фиксированный процент «на глазок», отказ от резерва из страха показать неуверенность, использование резерва как скрытой статьи расходов.

**Тип контракта определяет резерв** (расширяет [[contract-types]]):
- **Fixed Price** — риск перерасхода на исполнителе → максимальный резерв (10–50%).
- **Time & Material** — риск на заказчике → PM контролирует burn rate и прозрачность учёта времени.
- **Dedicated Team / Outstaff** — оплата по FTE в месяц → резервы минимальны, PM следит за загрузкой и простоями.

## Control Costs и Earned Value Management (EVM)
Базовые показатели:
- **PV (Planned Value)** — сколько должно быть освоено по плану.
- **AC (Actual Cost)** — сколько фактически потрачено.
- **EV (Earned Value)** — сколько реально заработано выполненной работой.

Индексы и прогнозы:
- **CV = EV − AC** (отклонение по стоимости).
- **SV = EV − PV** (отклонение по срокам).
- **CPI = EV / AC** — эффективность расходования (>1 — экономия, <1 — перерасход).
- **SPI = EV / PV** — эффективность по срокам.
- **EAC = BAC / CPI** — прогноз итоговой стоимости при сохранении текущей тенденции.
- **ETC = EAC − AC** — сколько ещё нужно потратить.
- **VAC = BAC − EAC** — прогнозируемое отклонение от исходного бюджета.

EVM связывает деньги, сроки и результат в единую картину для принятия управленческих решений (сократить скоуп, использовать резерв, эскалировать спонсору).
